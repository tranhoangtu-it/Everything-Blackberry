## 📦 How to Install These Apps

1. **Native `.bar` apps**: Download from CrackBerry forums or the community package repos. Install via Sachesi. See [Sideloading_Masterclass.md](Sideloading_Masterclass.md).

2. **Android `.apk` apps**: Download the specific version from APKMirror or the app's official source. Convert to `.bar` using Sachesi or install directly. See [Sideloading_Masterclass.md](Sideloading_Masterclass.md).

3. **Version pinning**: Once you have a working version of an app, **do not update it**. Newer versions almost always require newer Android versions that BB10's runtime cannot handle.
